# Adversarial Code Review

Inspect actual diff and context. Seek regressions, missing edge cases, unsafe assumptions and missing tests. For each issue: severity, file/line, failure scenario and suggested fix. Do not modify files or fabricate issues.

## Completion output
Summarize evidence, remaining uncertainty, and the next safe action.
