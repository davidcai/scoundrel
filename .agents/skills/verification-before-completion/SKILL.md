# Verification Before Completion

Choose targeted checks based on changed package. Run tests, typecheck, lint and diff check when available. Record command, exit status, and failing output. If unable to run, explicitly say unverified. Do not report success without evidence.

## Completion output
Summarize evidence, remaining uncertainty, and the next safe action.
